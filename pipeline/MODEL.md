# DRAGON SPORTS V1 模型規則

本文件說明官方提示如何產生、如何鎖定，以及如何以官方賽果結算。規則固定、可重現，沒有隨機成分。模型估計**不保證獲勝**。

V1 只覆蓋英超、西甲、德甲、法甲。盤口只限「勝負」（主勝／和局／客勝）以及「大小球」（預設盤口 2.5）。同一場比賽最多一條官方提示。寧缺毋濫：若沒有選項通過高信心門檻，該輪提案為零。

V1 **不使用、不估計、不填入 xG**。資料欄位缺失時會略過該項或標為無法使用，絕不臆造數字。

## 使用的資料

只使用 API 回傳、並已寫入快取或 `data/raw/bundle.json` 的資料：

- 積分榜：排名、積分、已賽場次、勝／和／負、得失球、主客場分項（如有）
- 近 45 日已完場賽事，用作近況（預設最近 5 場，開波前才計算）
- 賽前參考賠率（如有）：勝負，以及大小球 2.5。取各莊家中位數；若資料中有常見莊家則優先取其盤，但網站只顯示「參考賠率」數字，不推介任何莊家或投注站

不會使用傷兵、陣容、新聞或 xG。這些項目留待日後資料升級。

## 入球期望（柏松模型）

若雙方賽季已賽場次都達到 5 場，並且有得失球：

- 以賽季場均得／失球為主（七成），近況場均得／失球為輔（三成，近況須至少 3 場）
- 若主隊主場已賽達 4 場、客隊客場已賽達 4 場，而且聯賽有主客場均數，則改用主客場分項：
  - 主隊入球期望 = 主隊主場場均得球 × 客隊客場場均失球 ÷ 聯賽客場場均失球
  - 客隊入球期望 = 客隊客場場均得球 × 主隊主場場均失球 ÷ 聯賽主場場均失球
- 若只能用整體場均，則：
  - 主隊入球期望 =（主隊場均得球 + 客隊場均失球）÷ 2，再乘以主場係數 1.10
  - 客隊入球期望 =（客隊場均得球 + 主隊場均失球）÷ 2
- 以柏松分佈（入球上限 10）計算勝負與大小球 2.5 的概率
- 資料不足則此模型標為無法使用，不會填入假的入球期望

## 勝負後備評分（場均得分模型）

若柏松模型無法使用，勝負盤改用以下可加權合成的分數（缺項則重新分配權重，全部缺失則不提案）：

- 賽季場均得分差距（權重 0.30，除以 3 正規化）
- 主隊主場場均得分減客隊客場場均得分（0.25）
- 近況場均得分差距（0.25）
- 積分榜排名差距（0.20）
- 另加固定主場係數 0.12
- 以確定公式把分數轉成主勝／和局／客勝概率（和局在形勢接近時較高）

大小球**不會**用這套後備評分；沒有入球期望就不會出大小球提示。

## 參考賠率與「有值」

若有參考賠率，先把隱含概率按比例去掉抽水，再計算：

- 差值 = 模型概率 − 市場隱含概率
- 信心 = 模型概率 + 1.5 × max(差值, 0)

沒有賠率時，信心等於模型概率，而且門檻更高。

## 出料門檻（必須同時符合）

有參考賠率的勝負盤：差值至少 0.04、模型概率至少 0.48、信心至少 0.58。

沒有參考賠率的勝負盤：主勝或客勝的模型概率至少 0.60；和局至少 0.38，且比第二高選項高出至少 0.06。

有參考賠率的大小球：差值至少 0.04、模型概率至少 0.52、信心至少 0.58。

沒有參考賠率的大小球：模型概率至少 0.60。

同一場取信心最高、且過門檻的一個選項。每一輪最多鎖定 4 條。注碼只分 0.5 或 1.0 單位：信心達 0.62 用 1.0，否則用 0.5。

若全部未過門檻，本輪官方提示為**零**，這是正常情況。

## 鎖定

提示只可在開波前鎖定。鎖定後會寫入不可變編號、香港時間鎖定時戳，以及當下所用輸入的快照（包括用了哪些欄位、哪些無法使用）。

鎖定檔（`data/locked/*.json`）之後只允許附加官方賽果與單位盈虧，不得改寫選項、理據、賠率或快照。公開網站讀取由這些鎖定檔重建的 `data/tips.json`。

## 結算

只採納官方全場賽果（狀態 FT／AET／PEN），聯賽盤口以 90 分鐘全場比分為準。現行資料來源可能只提供 FT（90 分鐘比分），沒有 AET／PEN；有 FT 即可結算。取消、延期或腰斬標為無效，單位盈虧記 0，不計入勝率。

- 勝負：按主勝／和局／客勝對照選項。中則單位盈虧 = 注碼 ×（參考賠率 − 1）；不中則 −注碼
- 大小球：總入球大於盤口為大，小於為小；剛在盤口則走水，盈虧為 0
- 若沒有參考賠率：勝率仍計算，但獲勝的單位盈虧記為空白，不臆造派彩賠率；不中則仍記 −注碼

成績只由已結算提示重算。沒有已結算提示時，公開成績須顯示空白狀態，而不是看起來像往績的零勝率。

## 誠實原則

分析是估計，不是保證。對外文案不得使用「成日中」或任何保證勝出的說法。示範資料必須標明「示範資料，非真實往績」，且不得作為網站預設讀取的資料。
